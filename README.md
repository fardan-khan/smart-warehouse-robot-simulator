# Smart Warehouse Robot Simulator

AI course project. Simulated warehouse where robots deliver parcels. Compares
Simple Reflex, Goal-Based and Utility-Based agents with BFS, A*, Dijkstra,
Greedy and DFS path planning.

## How to run
1. pip install pygame-ce matplotlib notebook
2. Open Smart_Warehouse_Robot_Simulator.ipynb in Jupyter or VS Code
3. Run Cells 1-7, then Cell 8 for the GUI
4. Run Cell 10 for result tables, Cell 11 for charts
